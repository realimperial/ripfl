# cryPTodinheiro Blockchain RIPFL Protocol v1.0 alpha
Real Imperial Protocolo Financeiro Lusitano

O RIPFL é uma infraestrutura financeira baseada em blockchain destinada à gestão monetária, reservas estratégicas, crédito, pagamentos, ativos programáveis e serviços financeiros distribuídos.

## Componentes

- Sistema Monetário RIPFL
- Consenso Proof of Queue (PoQ)
- Endereçamento LFAS\-21
- Livro\-Razão Global
- Tesourarias
- Mercados
- Reserva Estratégica RIPFL\-108
- Crédito e Empréstimos
- Cashback e Recompensas
- Ativos Programáveis
